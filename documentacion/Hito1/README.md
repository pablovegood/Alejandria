### Configuración correcta del nombre y correo electrónico para que aparezca en los commits

La configuración del nombre y el correo electrónico que aparecerán en los commits se ha obtenido a partir de los siguientes comandos:
$ git config --global user.name "Pablo García Alvarado"
$ git config --global user.email "e.pabloalvarado@go.ugr.es"
